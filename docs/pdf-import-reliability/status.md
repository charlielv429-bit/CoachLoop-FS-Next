## 在Mac取得真实证据（不上传原PDF）

先本地备份未提交源码修改，保留`.env`及`.local-library`/自定义资料库目录。不要reset或删除资料库。

```bash
git fetch origin
git switch fix/pdf-import-reliability
# 若本地改动冲突，先保存改动；不要强制覆盖。
BACKEND_PORT=8001 bash scripts/dev.sh
```

确认终端给出的Vite地址，在浏览器访问它；5175不再被固定端口表误拒绝。另开终端执行：

```bash
.venv/bin/python scripts/diagnose_pdf_import.py "/真实路径/发生错误的旧扫描PDF.pdf" \
  --backend http://127.0.0.1:8001 --origin http://127.0.0.1:5175
```

此脚本只读文件，调用与当前预检相同的严格解析、资源限制与25秒时限，输出耗时、退出码、固定分类及修复建议；不导入资料、不跑OCR、不发送模型、不改.env、不输出原文或密钥。它不会生成或修复PDF。仅需回传诊断代码、异常类型、耗时、退出码及页数（若有）。也可提供有权共享的最小失败PDF；不要发送私人API Key。

测试脚本自身使用的是前轮自建三页PDF：0.23秒预检成功。它仅证明诊断工具可运行，不是旧扫描PDF的真实验收。
