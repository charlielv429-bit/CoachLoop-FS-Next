# CoachLoop-FS Next · MVP 1.5

面向花样滑冰教师与专项教练的中文 AI 教学对话 MVP。React + TypeScript + FastAPI，新增本地 SQLite 教材索引。独立于 CoachLoop-FS 旧项目。

## Mac 本地运行

需要 Python 3.11+（本次验证 3.12.14）、Node.js 22+（本次验证 24.22.1）和 npm。Mac 可用 Homebrew 安装：`brew install python@3.12 node@22`，并确保对应版本的 `python3`、`node`、`npm` 已加入 PATH；先用 `python3 --version`、`node --version` 检查。未在真实 Mac 设备上执行验收。

```bash
git clone https://github.com/charlielv429-bit/CoachLoop-FS-Next.git
cd CoachLoop-FS-Next
# 本 PR 合并前先切换到独立知识库开发分支
git switch feat/mvp1-5-local-pdf-rag
bash scripts/setup.sh
# 使用编辑器填写 backend/.env；不要将密钥提交到 Git
bash scripts/dev.sh
```

浏览器打开 http://localhost:5173 。Ctrl+C 停止两个服务。前端通过 Vite 转发 `/api` 到本机后端 8000 端口。端口需空闲；运行服务绑定本机，适合本地开发。

## MVP 1.5：从浏览器导入专项知识库

更新已有 Mac 项目前，先检查 `git status` 并本地备份或 stash 未提交的源码改动；不要使用 `reset --hard` 或覆盖原来的 `.env`。本版本不更改你的私人凭据，`scripts/setup.sh` 也不会覆盖已存在的 `backend/.env`。保留你已在 Mac 跑通的 Gemini `LLM_API_KEY`、`LLM_BASE_URL` 与 `LLM_MODEL`。

如果本机正在使用8001，继续这样启动（前端代理和后端使用同一变量）：

```bash
bash scripts/setup.sh
BACKEND_PORT=8001 bash scripts/dev.sh
```

也可仅在本机已有 `backend/.env` 添加 `BACKEND_PORT=8001`，再运行 `bash scripts/dev.sh`。命令行环境变量优先于文件设置。默认保持原来的8000；已自定义前端代理时请保留或合并本地改动，`BACKEND_URL` 可指定已有本机后端地址。不要提交个人 `.env`。本项目只支持本机单用户运行；不要把前后端改为监听 `0.0.0.0` 或将端口暴露到公网/局域网。

教师日常操作不需要终端、SQL或手动分块：

1. 进入「专项知识库」，批量选择或拖入最多7份有权使用的 PDF，选择教材并核对教材名、作者、版本及来源。
2. 点击「开始批量导入」。每份最多100MB、1500页；本地库最多30份、10000页。浏览器逐文件上传，后台每批5页处理并逐页提交检查点，关掉页面后已接收文档仍继续处理。
3. 查看每本书的原始页数、已处理/可检索页数、缺处理记录、失败、OCR低质量和待核对数。状态“分页处理完成”不代表专业审核通过，上传100%也不代表索引完整。
4. 使用搜索框查关键词，打开原页预览。原图保留在原 PDF 对应页面；预览由本机 PDFium 渲染，不发送给模型。点击原PDF以本机渲染的安全原页查看器打开准确的 `#page=N`，不会向浏览器交付可交互PDF。原件仍保存在本机。
5. 逐页核对正文、填写独立的印刷页码及有原文依据的章节。专业审核为独立勾选，不由 OCR 或文字提取自动授予。章节只从已有 PDF 书签有据提取，或由用户核对填写；无依据时为空。
6. 默认禁止向模型发送本地教材。可按教材开启许可；每轮提问仍需预览并勾选最多4个短片段（每条不超过480字符）。OCR正文即使高置信，也须人工核对后才能发送。没有可靠片段可选择“不使用本地片段”，模型应说明证据不足。
7. 「继续/重试」恢复缺失与失败页；「重建机器索引」保留已人工核对的页与页码。“清除索引”保留原PDF，但删除派生正文与核对记录并关闭云端许可；可重新处理。“删除本地教材”会移除原件和索引，两者均需确认。关闭许可不能撤回此前发给模型的内容；需要时清空旧会话。

支持预设的七份教材元信息（不随项目提供PDF）：王树本《花样滑冰》、李乡状等《花样滑冰技法与指导》、沈祖修/杨家声《怎样练习花样滑冰》、韦迪主编《花样滑冰》、《少年儿童业余训练教材·花样滑冰》、ISU Technical Panel Handbook Single Skating 2025–2026、《花样滑冰竞赛规则（1987）》。书名/作者/版本仍需你按实际文件确认。

### 可选的离线中文 OCR

文本型 PDF 无需 OCR。Mac 首次启用扫描页识别需安装免费的本机 Tesseract 与语言包：

```bash
brew install tesseract tesseract-lang
```

安装后重启后端，页面会检测 `chi_sim` + `eng`；缺引擎/语言包时说明原因，不会调用付费 OCR 或伪造正文。OCR置信度仅为引擎词级估计，不等同识别准确率。低质量页不进入可检索索引；高置信OCR可在本机搜索，但人工核对前不能交给云模型。扫描图中的动作本身不被自动分析或打分。

### 私有文件、安全与恢复边界

默认存储在项目的 `.local-library/`，可在本机环境设置 `COACHLOOP_LIBRARY_DIR` 改到其他私有目录。原件、SQLite/WAL索引、临时正文与预览都仅在运行后端的本机处理；原 PDF、全文和图片不会自动发送模型。SQLite FTS5 使用中文双字词与英文词，不引入云向量库。旧13条摘要保持可用，本地引用ID有独立命名空间；同书同作者同页的已选本地片段优先于旧摘要。

只传送明确选中的本地短片段，另保留原有摘要和对话历史的发送流程。云服务可能保留已经发送的请求；本地许可切换不能撤回。教师应先确认教材使用权。存储不做应用层加密，请使用你信任的本机账户；备份整个私有目录时也须注意隐私。

限制文件类型/实际魔数/大小/页数，拒绝加密、主动脚本、危险外部动作、动态XFA及嵌入附件；验证过的内部定位、普通注释和静态表单按被动模式处理；PDF解析、渲染、OCR运行在不继承模型凭据的有资源/超时限制子进程中。Mac使用CPU/超时/渲染尺寸限制，Linux另有内存地址空间上限；这不是完整的操作系统安全沙箱。索引任务使用单进程队列，请勿启动多个 Uvicorn worker 共用同一资料目录。

本机断电/进程退出后，下次启动会从逐页检查点续处理；失败页可重试。上传传输中断时需重新选文件上传，不做断点续传；已完整接收的原件按 SHA-256 去重。损坏页或超过单页24000字符处理上限的页会保留核对草稿、标记待核对并排除索引；不会宣称完整提取。原文检索不等于语义验证，使用前需回查原页。

## 真实模型 API

`backend/.env.example` 提供配置说明：

- `LLM_API_KEY`：服务商密钥，仅后端读取。
- `LLM_BASE_URL`：可信的 OpenAI 兼容 HTTPS API 根地址，默认 `https://api.openai.com/v1`。
- `LLM_MODEL`：账户可用模型，默认 `gpt-4o-mini`。

服务需支持 Chat Completions、JSON object 输出和 `max_tokens`。修改 `.env` 后重启后端。未配置密钥时不会调用模型；已配置仅表示存在凭据，首次成功响应后页面才显示已连接。请求中的对话文本和已检索摘要会发送给所选服务商，请先确认服务商的数据政策与摘要使用权。页面无文件或视频上传功能。停止按钮取消浏览器等待，不能保证撤回模型服务商已接受的请求。

每条消息最多 6000 字符、上下文 24000 字符、最多 12 轮；单进程每客户端每分钟 12 次请求、最多 3 个并发模型请求；上游超时 45 秒、整体 55 秒。当前为本地单用户 MVP，无生产级身份认证及跨进程限流，请勿直接公开部署。

## 环境变量示例

安装脚本仅在 `backend/.env` 不存在时创建文件；不会覆盖你已有的配置。使用编辑器填写以下内容，密钥仅在你自己的 Mac 上保存，不要粘贴到聊天或提交仓库：

```dotenv
LLM_API_KEY=YOUR_LOCAL_API_KEY
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o-mini
```

不要使用 `VITE_` 前缀保存密钥，前端不需要模型凭据。`.env`、`.env.*` 默认忽略，只有空凭据示例文件允许提交。个人资料应放在忽略的 `personal-data/`、`student-data/` 或 `private-data/`；不要将学生资料写入源码、教材摘要或测试夹具。Git 忽略规则无法自动识别任意文件内的敏感内容。

## 故障排查

- `python3` 或 `node` 版本不符：确认 Homebrew 对应工具已在 PATH；已有 `.venv` 使用旧 Python 时，先备份本地配置，再仅删除 `.venv` 并重新运行安装脚本。
- 安装失败：确认可访问 PyPI 与 npm registry，保留 TLS 校验；使用 `bash scripts/setup.sh` 查看出错命令，勿关闭证书验证。
- 8000 / 5173 端口占用：用 `lsof -nP -iTCP:8000 -sTCP:LISTEN` 或对应 5173 查看占用者，停止你自己的旧开发进程再启动。Ctrl+C 后若端口仍被占用也按此检查，勿盲目结束其他应用。
- 页面无法连接后端：确认终端有 Uvicorn 与 Vite 启动输出，并检查 `curl http://127.0.0.1:8000/api/status`。页面应从 Vite 的 5173 端口打开。
- 模型未连接：确认文件位置为 `backend/.env`、密钥非空，并重启后端。已配置不等于认证或真实响应成功。
- 认证失败 / 429 / 超时：分别检查服务商权限与模型名称、额度与请求频率、网络和服务状态；兼容服务须支持 JSON object 输出。错误提示不会显示密钥或上游原始响应。
- 引用校验失败：重新发送问题；若持续失败，检查服务商是否支持指定输出格式，勿绕过引用校验。教材状态 pending 属于待专业审核，不是配置错误。

## 教材资料与真实性

`data/sources.json` 已录入用户提供的 13 条资料：B02 的 PDF 90–93 页／印刷76–79页、B03 的 PDF39页／印刷29页，以及 L01–L08 每课45分钟的课程设计。

教材保留 `verification_status: pending` 和 `scan_checked: true`：用户已核对原始扫描页，但仍待专业教师审核。此类摘要可检索，引用卡片始终显示待审核；不能当作原文或正式技术标准。课程标为 `confirmed`，不代表教材规定的官方等级动作组合。本项目未独立查看原始 PDF。

检索使用中文双字词与英文词重叠排序，适合小型资料集；仅检索已核验、已确认课程，或明确核对过扫描页的非空记录。空白、未核对资料不参与检索。每轮结合历史用户问题，返回最多4条。出处卡片由后端记录生成，书名和页码不由模型编写；未知引用 ID、无引用的事实及自行输出书名/页码/链接会被拒绝。这不能保证语义完全正确，教师仍需核对原始教材。没有检索结果时不显示教材事实。

补充资料时记录书名、作者、PDF与印刷页码、摘要、来源类型及核实状态；经专业审核后再设为 `verified` 并补充 `verified_by`、`verified_at`、`verification_note`。不要将模型生成的文字改标为教材事实。数据每次检索重新读取。

## 结构与边界

- `backend/app/main.py`：模型 API、格式校验、错误和请求限制。
- `backend/app/knowledge.py`：最小检索模块。
- `frontend/src/`：对话、引用卡片、连接状态、停止与清空会话。
- `data/sources.json`：人工核验来源目录。

会话仅保存在当前网页内存，刷新即清除；后端不落盘对话。不进行正式技术评分，不替代现场指导或医疗意见。不支持视频分析、教案编辑器、数据库管理或完整 Agent 工作流。请勿输入真实学生个人信息及敏感数据；当前文字输入不包含自动脱敏系统。

## PDF兼容性专项修复

旧扫描文件的`PDF_ACTIVE_CONTENT_BLOCKED`可能是普通内部定位或静态表单被误拦，不能仅凭该代码确定对象。本分支细分动作类别、保持危险动作拒绝，并用本机安全原页替代交互式PDF响应。诊断脚本不会打印正文、脚本、URL或附件名称。规则、安全预览边界、自建测试结果与可直接复制的Mac文件选择器复验命令见 [专项验证说明](docs/pdf-import-compatibility/verification.md)。真实王树本PDF尚待用户Mac复验。
